## 📌 Project Overview
This repository contains the completed solutions for Lab 4b (Client-Side Scripting - JSON and jQuery). The lab focuses on creating valid JSON datasets, asynchronously fetching and displaying JSON data using the native JavaScript fetch() API with error handling, and comparing DOM/event handling methods between native JavaScript and jQuery 4.0.0.
